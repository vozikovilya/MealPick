## 🔧 Технические детали

### Компонент NotificationsView

**Расположение:** `src/components/ProfileScreen.tsx`

**Props:**
```typescript
interface NotificationsViewProps {
  notifications: Notification[];
  onBack: () => void;
  onUpdate: () => void;
}
```

**Состояния:**
```typescript
const [selectedNotification, setSelectedNotification] = useState<Notification | null>(null);
```

**Функции:**
- `handleMarkAsRead(notificationId)` - пометить одно уведомление как прочитанное
- `handleMarkAllAsRead()` - пометить все уведомления как прочитанные
- `getNotificationIcon(type)` - получить иконку для типа уведомления
- `getNotificationColor(type, isRead)` - получить цвет для уведомления

### API вызовы

**Загрузка уведомлений:**
```typescript
const notificationsResponse = await api.getNotifications();
setNotifications(notificationsResponse.data.notifications);
```

**Обновление уведомлений:**
```typescript
// Пометить одно как прочитанное
await api.updateNotifications({ notification_id: notificationId });

// Пометить все как прочитанные
await api.updateNotifications({ mark_all_read: true });
```

## 📊 Интеграция с другими компонентами

### Связь с Notifications.tsx

**Общие функции:**
- Оба компонента используют `api.getNotifications()`
- Оба используют `api.updateNotifications()`
- Оба отображают уведомления с одинаковой структурой

**Различия:**
- `Notifications.tsx` - отдельная вкладка в нижнем меню
- `ProfileScreen.tsx` → `NotificationsView` - часть профиля

**Синхронизация:**
- При прочтении уведомления в профиле, оно также помечается как прочитанное в основном списке уведомлений
- Счетчик непрочитанных обновляется в обоих местах

### Связь с App.tsx

**Обновление счетчика:**
```typescript
// В App.tsx
const [unreadCount, setUnreadCount] = useState(0);

// Загрузка уведомлений
const notifResponse = await api.getNotifications();
const count = notifResponse.data.notifications.filter(
  (n) => !n.is_read && n.type === 'swipe_request'
).length;
setUnreadCount(count);
```

**В ProfileScreen.tsx:**
```typescript
const unreadCount = notifications.filter((n) => !n.is_read).length;
```

## 🐛 Решение проблем

### Проблема 1: Уведомления не загружаются

**Симптом:** Список уведомлений пустой

**Решение:**
1. Проверьте консоль на наличие ошибок
2. Убедитесь, что API endpoint `/api/notifications/list.php` работает
3. Проверьте, что пользователь авторизован
4. Проверьте логи PHP на сервере

### Проблема 2: Счетчик не обновляется

**Симптом:** Бейдж не изменяется после прочтения уведомлений

**Решение:**
1. Убедитесь, что вызывается `onUpdate()` после прочтения
2. Проверьте, что `loadProfile()` перезагружает уведомления
3. Проверьте консоль на наличие ошибок

### Проблема 3: Кнопки действий не работают

**Симптом:** При нажатии на кнопку ничего не происходит

**Решение:**
1. Проверьте консоль на наличие ошибок
2. Убедитесь, что API endpoints работают
3. Проверьте, что уведомление имеет правильный тип
4. Проверьте логи PHP на сервере
