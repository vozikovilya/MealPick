# Инструкция по тестированию сохранения семьи

## 🔧 Утилиты отладки

В приложении доступны утилиты для проверки сохранения данных в localStorage. Откройте консоль браузера (F12) и используйте следующие команды:

### 1. `window.debugStorage()`
Показывает все данные из localStorage:
- Версию хранилища
- Текущего пользователя
- Профиль семьи
- Список пользователей
- Заявки на вступление
- Количество уведомлений и запросов

**Пример использования:**
```javascript
window.debugStorage();
```

### 2. `window.checkFamilyPreservation()`
Проверяет, сохраняется ли семья в localStorage:
- ✅ Семья найдена - показывает ID, название, владельца и участников
- ❌ Семья не найдена - сообщает об отсутствии семьи

**Пример использования:**
```javascript
window.checkFamilyPreservation();
```

### 3. `window.clearStorage()`
Очищает localStorage и перезагружает страницу:
- Удаляет все данные
- Перезагружает приложение
- Начинает с чистого состояния

**Пример использования:**
```javascript
window.clearStorage();
```

## 🐛 Диагностика проблем

### Проблема: Семья не сохраняется после выхода

**Симптомы:**
- Создаёте семью
- Выходите из аккаунта
- Входите снова
- Семья исчезла

**Диагностика:**
```javascript
// 1. Создайте семью
// 2. Проверьте сохранение
window.checkFamilyPreservation(); // Должно быть ✅

// 3. Выйдите из аккаунта
// 4. Проверьте сохранение после выхода
window.checkFamilyPreservation(); // Должно быть ✅

// 5. Если на шаге 4 результат ❌, значит logout() обнуляет familyProfile
```

**Решение:**
Проверьте функцию `logout()` в `src/store.ts`:
```typescript
logout: () => {
  set({ 
    currentUserId: null,
    pendingNotification: null,
    // familyProfile НЕ должен обнуляться!
  });
},
```

---

### Проблема: Семья исчезает при регистрации нового пользователя

**Симптомы:**
- Пользователь А создаёт семью
- Регистрируется пользователь Б
- Семья пользователя А исчезает

**Диагностика:**
```javascript
// 1. Создайте семью как пользователь А
window.checkFamilyPreservation(); // ✅

// 2. Зарегистрируйте пользователя Б
// 3. Проверьте сохранение семьи
window.checkFamilyPreservation(); // Должно быть ✅

// 4. Если результат ❌, значит register() обнуляет familyProfile
```

**Решение:**
Проверьте функцию `register()` в `src/store.ts`:
```typescript
register: (email, username, password, name, avatar = '👤') => {
  // ...
  set({
    users: [...users, newUser],
    currentUserId: newUser.id,
    // familyProfile НЕ должен обнуляться!
    pendingNotification: null,
  });
}
```

---

### Проблема: Семья не загружается из localStorage

**Симптомы:**
- Семья создаётся
- Страница перезагружается
- Семья исчезла

**Диагностика:**
```javascript
// 1. Создайте семью
// 2. Перезагрузите страницу (F5)
// 3. Проверьте сохранение
window.checkFamilyPreservation(); // Должно быть ✅

// 4. Если результат ❌, значит migrate() не восстанавливает familyProfile
```

**Решение:**
Проверьте функцию `migrate()` в `src/store.ts`:
```typescript
migrate: (persistedState: any) => {
  if (persistedState?.users && persistedState.users.length > 0) {
    return {
      users: persistedState.users,
      familyProfile: persistedState.familyProfile || null, // ✅ Должно быть
      // ...
    };
  }
}
```

## 📊 Ожидаемое поведение

### ✅ Правильное поведение

1. **Семья сохраняется в localStorage** после создания
2. **Семья не удаляется при выходе** из аккаунта
3. **Семья не удаляется при регистрации** нового пользователя
4. **Семья восстанавливается при входе** пользователя, если он является её членом
5. **Семья не видна пользователям**, которые не являются её членами
6. **Семья удаляется только явно** через функцию `deleteFamilyProfile()`

### ❌ Неправильное поведение

1. Семья исчезает после выхода из аккаунта
2. Семья исчезает после регистрации нового пользователя
3. Семья не восстанавливается после перезагрузки страницы
4. Семья видна пользователям, которые не являются её членами
5. Семья удаляется при удалении аккаунта одного из участников
