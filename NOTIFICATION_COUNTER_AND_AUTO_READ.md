### 2. Автоматическое прочтение при просмотре

**Логика работы:**
1. Пользователь открывает блок "Запросы"
2. Intersection Observer отслеживает видимость каждого уведомления
3. Если уведомление находится в зоне видимости **2 секунды** → автоматически помечается как прочитанное
4. Счётчик непрочитанных обновляется в реальном времени
5. Обновляется бейдж в нижней навигации

**Технические детали:**
```typescript
// Intersection Observer с threshold 0.5
const observer = new IntersectionObserver(
  (entries) => {
    entries.forEach((entry) => {
      const notificationId = Number(entry.target.getAttribute('data-notification-id'));
      
      if (entry.isIntersecting) {
        // Уведомление стало видимым - запускаем таймер на 2 секунды
        const timer = setTimeout(() => {
          handleMarkAsRead(notificationId);
        }, 2000);
        
        visibilityTimers.current.set(notificationId, timer);
      } else {
        // Уведомление стало невидимым - отменяем таймер
        const timer = visibilityTimers.current.get(notificationId);
        if (timer) {
          clearTimeout(timer);
          visibilityTimers.current.delete(notificationId);
        }
      }
    });
  },
  { threshold: 0.5 } // 50% площади уведомления должно быть видно
);
```

## 🔄 Как работает синхронизация

### Сценарий 1: Пользователь открывает блок "Запросы"

```
1. Пользователь нажимает на вкладку "Запросы"
   ↓
2. Загружаются уведомления из API
   ↓
3. Intersection Observer начинает отслеживать видимость
   ↓
4. Пользователь прокручивает список
   ↓
5. Уведомление попадает в зону видимости (50% площади)
   ↓
6. Запускается таймер на 2 секунды
   ↓
7. Если уведомление остаётся видимым 2 секунды:
   - Вызывается API: PUT /api/notifications/update.php
   - Уведомление помечается как прочитанное
   - Счётчик обновляется
   - Бейдж в нижней навигации уменьшается
   ↓
8. Если пользователь прокручивает дальше до истечения 2 секунд:
   - Таймер отменяется
   - Уведомление остаётся непрочитанным
```

### Сценарий 2: Множественные уведомления

```
1. У пользователя 5 непрочитанных уведомлений
   ↓
2. Открывает блок "Запросы"
   ↓
3. Видит первые 3 уведомления на экране
   ↓
4. Через 2 секунды все 3 помечаются как прочитанные
   ↓
5. Счётчик уменьшается: 5 → 2
   ↓
6. Пользователь прокручивает вниз
   ↓
7. Видит оставшиеся 2 уведомления
   ↓
8. Через 2 секунды они тоже помечаются как прочитанные
   ↓
9. Счётчик: 2 → 0
   ↓
10. Бейдж в нижней навигации исчезает
```

## 📊 Технические детали

### Intersection Observer

**Параметры:**
```typescript
{
  threshold: 0.5  // 50% площади уведомления должно быть видно
}
```

**Почему 50%?**
- Если показать хотя бы половину уведомления - пользователь его "видит"
- Избегаем случайного прочтения при быстрой прокрутке
- Баланс между UX и точностью

### Таймер прочтения

**Длительность:** 2000 мс (2 секунды)

**Почему 2 секунды?**
- Достаточно времени, чтобы пользователь прочитал уведомление
- Не слишком долго - не раздражает
- Стандартное время для "просмотра" в UX

### Оптимизация производительности

**Использование refs:**
```typescript
const notificationRefs = useRef<Map<number, HTMLDivElement>>(new Map());
const visibilityTimers = useRef<Map<number, ReturnType<typeof setTimeout>>>(new Map());
```

**Почему refs?**
- Не вызывают перерендер при изменении
- Хранят ссылки на DOM элементы
- Хранят таймеры для отмены

**Очистка при размонтировании:**
```typescript
return () => {
  observer.disconnect();
  visibilityTimers.current.forEach((timer) => clearTimeout(timer));
  visibilityTimers.current.clear();
};
```

## 🐛 Решение проблем

### Проблема 1: Уведомления не помечаются как прочитанные

**Симптом:** Счётчик не уменьшается

**Решение:**
1. Проверьте консоль на наличие ошибок
2. Убедитесь, что Intersection Observer поддерживается браузером
3. Проверьте, что API endpoint `/api/notifications/update.php` работает
4. Проверьте логи PHP на сервере

### Проблема 2: Счётчик не обновляется

**Симптом:** Бейдж в нижней навигации не изменяется

**Решение:**
1. Проверьте, что callback `onUnreadCountChange` передаётся в Notifications
2. Убедитесь, что `setUnreadCount` вызывается при изменении уведомлений
3. Проверьте консоль на наличие ошибок

### Проблема 3: Уведомления помечаются слишком быстро

**Симптом:** Уведомления прочитываются мгновенно

**Решение:**
1. Увеличьте порог видимости в Intersection Observer:
   ```typescript
   { threshold: 0.8 }  // 80% площади должно быть видно
   ```
2. Увеличьте длительность таймера:
   ```typescript
   setTimeout(() => {
     handleMarkAsRead(notificationId);
   }, 3000);  // 3 секунды вместо 2
   ```
