### 3. Логика удаления блюд

**Проблема:**
- Владелец блюда мог удалить его, даже если не был главой семьи или поварушкой
- При смене роли в семье права на удаление не обновлялись

**Решение:**

#### Frontend (RecipeList.tsx):

**Было:**
```typescript
const canDeleteRecipe = (recipe: Recipe): boolean => {
  if (!currentUser) return false;
  
  // Владелец блюда всегда может удалить
  if (recipe.user_id === currentUser.id) return true;
  
  // Глава семьи может удалить любое блюдо
  if (userFamily && userFamily.owner_id === currentUser.id) return true;
  
  // Поварушка может удалить любое блюдо
  if (userFamily) {
    const member = userFamily.members?.find((m: any) => m.id === currentUser.id);
    if (member && member.role === 'chef') return true;
  }
  
  return false;
};
```

**Стало:**
```typescript
const canDeleteRecipe = (recipe: Recipe): boolean => {
  if (!currentUser || !userFamily) return false;
  
  // Глава семьи может удалить любое блюдо
  if (userFamily.owner_id === currentUser.id) return true;
  
  // Поварушка может удалить любое блюдо
  const member = userFamily.members?.find((m: any) => m.id === currentUser.id);
  if (member && member.role === 'chef') return true;
  
  return false;
};
```

**Изменения:**
- ✅ Убрана проверка на владельца блюда
- ✅ Удаление доступно только главе семьи и поварушке
- ✅ Добавлена проверка на наличие семьи (`!userFamily`)

#### Backend (delete.php):

**Было:**
```php
// Проверка прав на удаление
$canDelete = false;

// Владелец блюда может удалить
if ($recipe['user_id'] == $userId) {
    $canDelete = true;
} else {
    // Глава семьи или поварушка могут удалить
    $stmt = $db->prepare("
        SELECT f.owner_id, fm.role
        FROM families f
        JOIN family_members fm ON f.id = fm.family_id
        WHERE fm.user_id = ? AND fm.status = 'accepted'
    ");
    $stmt->execute([$userId]);
    $family = $stmt->fetch();
    
    if ($family) {
        // Глава семьи или поварушка
        if ($family['owner_id'] == $userId || $family['role'] === 'chef') {
            $canDelete = true;
        }
    }
}

if (!$canDelete) {
    sendError('У вас нет прав на удаление этого блюда', 403);
}
```

**Стало:**
```php
// Проверка прав на удаление
$canDelete = false;

// Глава семьи или поварушка могут удалить любое блюдо
$stmt = $db->prepare("
    SELECT f.owner_id, fm.role
    FROM families f
    JOIN family_members fm ON f.id = fm.family_id
    WHERE fm.user_id = ? AND fm.status = 'accepted'
");
$stmt->execute([$userId]);
$family = $stmt->fetch();

if ($family) {
    // Глава семьи или поварушка
    if ($family['owner_id'] == $userId || $family['role'] === 'chef') {
        $canDelete = true;
    }
}

if (!$canDelete) {
    sendError('У вас нет прав на удаление этого блюда. Только глава семьи или поварушка могут удалять блюда.', 403);
}
```

**Изменения:**
- ✅ Убрана проверка на владельца блюда
- ✅ Удаление доступно только главе семьи и поварушке
- ✅ Улучшено сообщение об ошибке

#### Polling для обновления прав (RecipeList.tsx):

**Добавлено:**
```typescript
useEffect(() => {
  loadRecipes();
  loadUserData();
  
  // Polling для обновления данных семьи (проверка смены ролей)
  const familyPollInterval = setInterval(() => {
    loadUserData();
  }, 10000); // Каждые 10 секунд
  
  return () => clearInterval(familyPollInterval);
}, []);
```

**Изменения:**
- ✅ Добавлен polling каждые 10 секунд
- ✅ При смене роли в семье права на удаление обновляются автоматически
- ✅ Очистка интервала при размонтировании компонента

## 🐛 Решение проблем

### Проблема 1: Кнопки удаления не появляются после назначения поварушки

**Симптом:** После назначения роли поварушки кнопки удаления не появляются

**Решение:**
1. Подождите 10 секунд (polling обновит данные)
2. Обновите страницу (F5)
3. Проверьте консоль на наличие ошибок
4. Убедитесь, что роль действительно назначена в базе данных

### Проблема 2: Ошибка "У вас нет прав на удаление этого блюда"

**Симптом:** При попытке удалить блюдо появляется ошибка

**Решение:**
1. Проверьте, что вы являетесь главой семьи или поварушкой
2. Убедитесь, что вы состоите в семье
3. Проверьте логи backend (`backend/logs/error.log`)
4. Проверьте роль в базе данных:
   ```sql
   SELECT fm.role FROM family_members fm
   WHERE fm.user_id = YOUR_USER_ID AND fm.status = 'accepted';
   ```

### Проблема 3: Страница "прыгает" при смене вида

**Симптом:** При переключении между list и grid view страница дёргается

**Решение:**
1. Убедитесь, что загружен новый файл `RecipeList.tsx`
2. Очистите кэш браузера (Ctrl+Shift+R)
3. Проверьте, что классы содержат `py-2` вместо `py-1`
