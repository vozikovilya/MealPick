# 🔧 Диагностика проблемы с сохранением семьи

## ⚡ Быстрая проверка (30 секунд)

### 1. Откройте консоль браузера
- Нажмите `F12` или `Ctrl+Shift+I`
- Перейдите на вкладку **Console**

### 2. Создайте семью
- Войдите в аккаунт
- Перейдите в "Профиль" → "Профиль семьи"
- Создайте семью

### 3. Проверьте логи в консоли

Вы должны увидеть:
```
🏠 Создание семьи: { currentUserId: "user_...", existingFamily: null }
✅ Семья создана: { id: "family_...", name: "...", ... }
🔍 Проверка после создания: { familyProfile: {...}, localStorage: "..." }
```

### 4. Перезагрузите страницу (F5)

### 5. Проверьте сохранение

В консоли выполните:
```javascript
window.diagnoseFamilyStorage();
```

**Если семья сохраняется**, вы увидите:
```
✅ familyProfile найден
  - ID: family_...
  - Название: ...
```

**Если семья НЕ сохраняется**, вы увидите:
```
⚠️ familyProfile отсутствует или null
```

---

## 📋 Что делать дальше

### Если семья НЕ сохраняется после перезагрузки:

1. **Скопируйте полный вывод консоли** после создания семьи
2. **Выполните `window.diagnoseFamilyStorage()`** и скопируйте результат
3. **Отправьте эту информацию** для анализа

### Если семья сохраняется, но не отображается в UI:

1. **Проверьте, что вы находитесь на вкладке "Профиль семьи"**
2. **Проверьте консоль на наличие ошибок**
3. **Перезагрузите страницу**

## 📞 Нужна помощь?

Соберите следующую информацию:

1. Скриншот консоли после создания семьи
2. Вывод `window.diagnoseFamilyStorage()` до и после перезагрузки
3. Версия хранилища:
   ```javascript
   JSON.parse(localStorage.getItem('meal-picker-storage')).version
   ```

Отправьте эту информацию для дальнейшего анализа.
