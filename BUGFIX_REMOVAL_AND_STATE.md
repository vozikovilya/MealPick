# 🔧 Исправление проблем с удалением участников и сохранением состояния

## ✅ Исправленные проблемы

### 1. SQL ошибка при удалении участника из семьи

**Проблема:**
```
Ошибка сервера: SQLSTATE[42S22]: Column not found: 1054 Unknown column 'familyId' in 'field list'
```

**Причина:**
В файле `backend/api/family/remove-member.php` была попытка обновить колонку `familyId` в таблице `users`, но такой колонки не существует. Связь между пользователем и семьёй хранится в таблице `family_members`.

**Решение:**
Удалена строка с некорректным SQL запросом:
```php
// БЫЛО (неправильно):
$stmt = $db->prepare("UPDATE users SET familyId = NULL WHERE id = ?");
$stmt->execute([$memberId]);

// СТАЛО (правильно):
// Эта строка удалена, так как связь уже удаляется через family_members
```

**Файл:** `backend/api/family/remove-member.php`

---

### 2. Убрано уведомление подтверждения при удалении

**Проблема:**
При удалении участника из семьи появлялось уведомление подтверждения, которое не нужно.

**Решение:**
Убран вызов `await onCreate()` и добавлена перезагрузка страницы:
```typescript
// БЫЛО:
const handleRemoveMemberFromFamily = async (memberId: number) => {
  try {
    await api.removeFamilyMember(memberId);
    await onCreate(); // Перезагружаем данные семьи
    setShowRemoveConfirm(null);
    setOpenActionsMenu(null);
  } catch (error: any) {
    alert(error.message || 'Ошибка удаления участника');
  }
};

// СТАЛО:
const handleRemoveMemberFromFamily = async (memberId: number) => {
  try {
    await api.removeFamilyMember(memberId);
    setShowRemoveConfirm(null);
    setOpenActionsMenu(null);
    // Перезагружаем страницу для обновления состояния
    window.location.reload();
  } catch (error: any) {
    alert(error.message || 'Ошибка удаления участника');
  }
};
```

**Файл:** `src/components/ProfileScreen.tsx`

### 4. Сохранение состояния экрана при перезагрузке

**Проблема:**
При перезагрузке страницы пользователь всегда возвращался на экран "Меню", даже если находился в другом блоке.

**Решение:**
Добавлено сохранение текущего экрана в localStorage:

```typescript
// Восстанавливаем сохранённый экран из localStorage
const savedScreen = localStorage.getItem('currentScreen') as Screen | null;
const [screen, setScreen] = useState<Screen>(savedScreen || 'recipes');

// Сохраняем текущий экран в localStorage при изменении
useEffect(() => {
  localStorage.setItem('currentScreen', screen);
}, [screen]);

// Очищаем сохранённый экран при выходе
const handleLogout = () => {
  api.logout();
  setIsAuthenticated(false);
  setCurrentUser(null);
  setScreen('recipes');
  localStorage.removeItem('currentScreen');
};
```

**Файл:** `src/App.tsx`
