```tsx
  );
};

// Отправка каждому выбранному участнику

```

### 4. ✅ Новый экран "Детали запроса"

**Назначение:**
- Показывает полную информацию о запросе
- Отображает статусы ответов всех участников
- Показывает кто что выбрал

**Функциональность:**

#### Информация о запросе:
```tsx
<div className="bg-white rounded-2xl border border-gray-200 p-5">
  <span className="text-3xl">{request.from_user_avatar}</span>
  <p className="font-semibold">{request.from_user_name}</p>
  <p className="text-xs">{formattedDate}</p>
  <div className={statusClass}>
    {request.status === 'completed' ? '✅ Завершён' : '⏳ Ожидает'}
  </div>
  {request.message && (
    <div className="bg-pink-50">
      💌 "{request.message}"
    </div>
  )}
</div>
```

#### Статусы ответов:
```tsx
{allRecipients.map(recipient => {
  const hasResponded = responses[recipient.id] !== undefined;
  return (
    <div className={hasResponded ? 'bg-green-50' : 'bg-gray-50'}>
      <span>{recipient.avatar}</span>
      <p>{recipient.name}</p>
      {hasResponded ? (
        <p className="text-green-600">
          ✅ Выбрал {selectedRecipeIds.length} блюд
        </p>
      ) : (
        <p className="text-gray-500">
          ⏳ Ожидает ответа
        </p>
      )}
    </div>
  );
})}
```

#### Выбранные блюда по участникам:
```tsx
{allRecipients.map(recipient => {
  const selectedRecipeIds = responses[recipient.id] || [];
  const selectedRecipes = recipes.filter(r => 
    selectedRecipeIds.includes(r.id)
  );
  
  return (
    <div>
      <div className="flex items-center gap-2">
        <span>{recipient.avatar}</span>
        <p>{recipient.name}</p>
      </div>
      {selectedRecipes.map(recipe => (
        <div className="bg-green-50">
          <img src={recipe.image_urls[0]} />
          <p>{recipe.name}</p>
          <Check className="text-green-500" />
        </div>
      ))}
    </div>
  );
})}
```

#### Общая статистика:
```tsx
{recipes.map(recipe => {
  const selectedCount = Object.values(responses).reduce(
    (count, selectedIds) => 
      count + (selectedIds.includes(recipe.id) ? 1 : 0), 
    0
  );
  
  return (
    <div>
      <img src={recipe.image_urls[0]} />
      <p>{recipe.name}</p>
      {selectedCount > 0 && (
        <div className="bg-orange-100">
          Выбрано: {selectedCount}
        </div>
      )}
    </div>
  );
})}
```

## 🔄 Обновлённый цикл взаимодействия

### Сценарий 1: Отправка всей семье

```
1. Отправитель выбирает "Всей семье"
2. Выбирает блюда/категории/доставку
3. Добавляет сообщение
4. Нажимает "Отправить запрос"
   ↓
5. Система создаёт 1 запрос для всей семьи
6. Система создаёт уведомления для всех участников
   ↓
7. Каждый участник получает уведомление
8. Каждый участник свайпает блюда
9. Каждый участник отправляет выбор
   ↓
10. Система обновляет статусы в запросе
11. Отправитель получает уведомления о каждом ответе
   ↓
12. Отправитель нажимает "Подробнее"
13. Открывается экран "Детали запроса"
14. Отправитель видит:
    - Кто ответил ✅
    - Кто ожидает ⏳
    - Что каждый выбрал
    - Общую статистику
```

---

### Сценарий 2: Отправка нескольким участникам

```
1. Отправитель выбирает "Выбрать участников"
2. Отмечает нескольких участников (например, Мария и Пётр)
3. Выбирает блюда/категории/доставку
4. Добавляет сообщение
5. Нажимает "Отправить запрос"
   ↓
6. Система создаёт 2 отдельных запроса:
   - 1 запрос для Марии
   - 1 запрос для Петра
7. Система создаёт уведомления для Марии и Петра
   ↓
8. Появляется модалка:
   "Отправлено участникам:
    👤 Мария
    👤 Пётр"
   ↓
9. Мария и Пётр получают уведомления
10. Каждый свайпает блюда
11. Каждый отправляет выбор
   ↓
12. Отправитель получает уведомления о каждом ответе
13. Отправитель нажимает "Подробнее"
14. Открывается экран "Детали запроса"
15. Отправитель видит статусы всех ответов
```
