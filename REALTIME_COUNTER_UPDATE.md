# 🔄 Обновление счётчика уведомлений в реальном времени

## ✅ Что реализовано

Счётчик непрочитанных уведомлений теперь обновляется **автоматически без перезагрузки страницы** на всех экранах приложения.

---

## 🎯 Как это работает

### Механизм обновления

**1. Polling в App.tsx (глобальный)**
- Работает на **всех страницах** приложения
- Проверяет уведомления каждые **5 секунд**
- Автоматически обновляет счётчик непрочитанных
- Показывает toast уведомления при появлении новых

**2. Callback в Notifications.tsx (локальный)**
- Работает только на странице **"Запросы"**
- Обновляет счётчик при автоматическом прочтении уведомлений
- Срабатывает через 2 секунды видимости уведомления

## 🔧 Технические детали

### Polling в App.tsx

```typescript
useEffect(() => {
  if (!isAuthenticated) return;

  const checkForNewNotifications = async () => {
    const response = await api.getNotifications();
    const notifications = response.data.notifications;

    // Обновляем счётчик непрочитанных уведомлений
    const unreadCount = notifications.filter((n: any) => !n.is_read).length;
    setUnreadCount(unreadCount);

    // Показываем toast уведомления для новых
    const newNotifications = notifications.filter(
      (n: any) => new Date(n.created_at).getTime() > lastCheckRef.current
    );

    if (newNotifications.length > 0) {
      newNotifications.forEach((notification: any) => {
        if (notification.type === 'swipe_request') {
          handleNewSwipeRequest(notification.request_id, notification.from_user_name);
        } else if (notification.type === 'swipe_response') {
          handleNewSwipeResponse(notification.request_id, notification.from_user_name);
        }
      });
    }
  };

  checkForNewNotifications();
  const intervalId = setInterval(checkForNewNotifications, 5000); // Каждые 5 секунд

  return () => clearInterval(intervalId);
}, [isAuthenticated]);
```

### Callback в Notifications.tsx

```typescript
useEffect(() => {
  const unreadCount = notifications.filter((n) => !n.is_read).length;
  if (onUnreadCountChange) {
    onUnreadCountChange(unreadCount);
  }
}, [notifications, onUnreadCountChange]);
```

## 🐛 Решение проблем

### Проблема 1: Счётчик не обновляется

**Симптом:** Бейдж не изменяется при появлении новых уведомлений

**Решение:**
1. Откройте DevTools (F12) → вкладка Network
2. Проверьте, что запросы к `/api/notifications/list.php` отправляются каждые 5 секунд
3. Проверьте консоль на наличие ошибок
4. Убедитесь, что пользователь авторизован
5. Проверьте логи PHP на сервере

### Проблема 2: Toast уведомления не появляются

**Симптом:** Новые уведомления не показываются в правом верхнем углу

**Решение:**
1. Проверьте консоль на наличие ошибок
2. Убедитесь, что API возвращает новые уведомления
3. Проверьте, что `handleNewSwipeRequest` и `handleNewSwipeResponse` вызываются
4. Проверьте компонент `ToastNotifications`

### Проблема 3: Счётчик не синхронизируется между вкладками

**Симптом:** В одной вкладке счётчик обновляется, в другой - нет

**Решение:**
1. Это нормальное поведение - каждая вкладка имеет свой polling
2. Подождите 5-10 секунд для синхронизации
3. Убедитесь, что обе вкладки авторизованы под одним аккаунтом
