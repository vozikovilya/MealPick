### 2. Уведомления в реальном времени

**Возможности:**
- Мгновенные всплывающие уведомления (toast)
- Автоматическая проверка новых уведомлений каждые 5 секунд
- Уведомления о новых запросах на выбор блюд
- Уведомления о полученных ответах
- Автоматическое исчезновение через 10 секунд
- Кнопки действий для быстрого перехода

**Как это работает:**

#### Сценарий 1: Отправка запроса на выбор блюд

```
1. Пользователь А отправляет запрос
   ↓
2. Через 5 секунд пользователь Б получает toast уведомление:
   ┌─────────────────────────────────┐
   │ 🍽️ Новый запрос на выбор блюд  │
   │                                 │
   │ Пользователь А отправил(а) вам  │
   │ запрос на выбор блюд            │
   │                                 │
   │ [Выбрать блюда]                │
   └─────────────────────────────────┘
   ↓
3. Пользователь Б нажимает "Выбрать блюда"
   ↓
4. Открывается экран свайпов
   ↓
5. Пользователь Б выбирает блюда и отправляет ответ
   ↓
6. Через 5 секунд пользователь А получает toast уведомление:
   ┌─────────────────────────────────┐
   │ ✅ Получен ответ на запрос      │
   │                                 │
   │ Пользователь Б выбрал(а) блюда  │
   │                                 │
   │ [Посмотреть выбор]             │
   └─────────────────────────────────┘
   ↓
7. Пользователь А нажимает "Посмотреть выбор"
   ↓
8. Открывается экран с деталями запроса
```

**Техническая реализация:**

**Хук `useRealTimeNotifications`:**
- Периодически проверяет новые уведомления (каждые 5 секунд)
- Фильтрует только новые уведомления по времени
- Вызывает callback функции при получении новых уведомлений
- Автоматически отключается при выходе из аккаунта

**Компонент `ToastNotifications`:**
- Отображает уведомления в правом верхнем углу
- Анимация появления/исчезновения (spring animation)
- Градиентная полоска сверху (оранжевая для запросов, зелёная для ответов)
- Аватар отправителя
- Кнопка действия для быстрого перехода
- Кнопка закрытия
- Автоматическое исчезновение через 10 секунд

## 📊 Технические детали

### API Endpoints

**Новый endpoint:**
```
PUT /api/family/update.php
```

**Параметры:**
```json
{
  "name": "Новое название",
  "avatar": "🏠"
}
```

**Ответ:**
```json
{
  "success": true,
  "message": "Семья обновлена",
  "data": {
    "family": {
      "id": 1,
      "name": "Новое название",
      "avatar": "🏠",
      ...
    }
  }
}
```

### Polling механизм

**Интервал проверки:** 5 секунд (5000 мс)

**Логика:**
1. При загрузке приложения запускается polling
2. Каждые 5 секунд проверяются новые уведомления
3. Если есть новые уведомления - показываются toast
4. При выходе из аккаунта polling останавливается

**Оптимизация:**
- Предотвращение параллельных запросов (флаг `isRunning`)
- Фильтрация только новых уведомлений по времени
- Автоматическая очистка при размонтировании компонента

### Toast уведомления

**Позиция:** Правый верхний угол экрана

**Анимация:**
- Появление: `opacity: 0 → 1`, `x: 100 → 0`, `scale: 0.9 → 1`
- Исчезновение: `opacity: 1 → 0`, `x: 0 → 100`, `scale: 1 → 0.9`
- Тип анимации: `spring` (damping: 20, stiffness: 300)

**Автозакрытие:** Через 10 секунд

**Максимальное количество:** Не ограничено (можно показывать несколько одновременно)

## 🐛 Решение проблем

### Проблема 1: Уведомления не появляются

**Симптом:** Toast уведомления не отображаются

**Решение:**
1. Проверьте, что вы авторизованы
2. Откройте консоль браузера (F12)
3. Проверьте на наличие ошибок
4. Убедитесь, что polling запущен:
   ```javascript
   // В консоли браузера
   console.log('Polling активен');
   ```

### Проблема 2: Кнопка "Редактировать семью" не видна

**Симптом:** Кнопка не отображается в профиле семьи

**Решение:**
1. Убедитесь, что вы являетесь главой семьи
2. Проверьте, что загружен новый файл `ProfileScreen.tsx`
3. Очистите кэш браузера (Ctrl+Shift+R)

### Проблема 3: Ошибка при сохранении изменений

**Симптом:** При нажатии "Сохранить" появляется ошибка

**Решение:**
1. Убедитесь, что загружен файл `backend/api/family/update.php`
2. Проверьте права доступа к файлу (644)
3. Проверьте логи ошибок PHP: `backend/logs/error.log`
