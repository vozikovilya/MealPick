## 🔄 Логика работы

### Сценарий 1: Пользователь без семьи

1. Пользователь открывает блок "Семья"
2. Видит две опции:
   - Присоединиться к семье (по ссылке)
   - Создать новую семью
3. Выбирает одну из опций
4. Действует соответственно

### Сценарий 2: Отправка заявки на вступление

1. Пользователь вставляет ссылку-приглашение
2. Нажимает "Отправить заявку"
3. Backend создаёт запись в `family_join_requests`
4. Появляется поп-ап "Заявка отправлена!"
5. После закрытия поп-апа отображается секция "Заявка на рассмотрении"
6. Глава семьи получает уведомление в колокольчике

### Сценарий 3: Ответ главы семьи на заявку

**Если глава семьи принимает заявку:**
1. Глава семьи нажимает "Принять"
2. Backend:
   - Обновляет статус заявки на 'accepted'
   - Добавляет пользователя в `family_members`
   - Создаёт уведомление для заявителя
3. Заявитель:
   - Получает уведомление в колокольчике
   - При открытии блока "Семья" видит информацию о семье
   - Секция "Заявка на рассмотрении" исчезает

**Если глава семьи отклоняет заявку:**
1. Глава семьи нажимает "Отклонить"
2. Backend:
   - Обновляет статус заявки на 'rejected'
   - Создаёт уведомление для заявителя
3. Заявитель:
   - Получает уведомление в колокольчике
   - При открытии блока "Семья" снова видит формы создания/присоединения
   - Секция "Заявка на рассмотрении" исчезает

### Сценарий 4: Управление семьёй (для главы)

1. Глава семьи открывает блок "Семья"
2. Видит:
   - Информацию о семье
   - Кнопку "Редактировать семью"
   - Список участников с кнопками "Действия"
   - Список заявок на вступление (если есть)
   - Ссылку-приглашение
   - Кнопку "Удалить профиль семьи"
3. Может:
   - Редактировать название и аватар семьи
   - Назначать роли (Поварушка)
   - Удалять участников
   - Принимать/отклонять заявки
   - Копировать/делиться ссылкой-приглашением
   - Удалить семью

## 📊 Преимущества новой структуры

### 1. Чёткое разделение функций

**Было:**
- Профиль содержал всё: личный профиль, семья, уведомления
- Путаница в навигации
- Дублирование функций

**Стало:**
- "Я" - только личный профиль
- "Семья" - только управление семьёй
- "Колокольчик" - только уведомления
- Чёткая логика и навигация

### 2. Удобство использования

**Было:**
- Нужно было заходить в профиль для управления семьёй
- Уведомления дублировались
- Не было видно текущего запроса на вступление

**Стало:**
- Семья в отдельном блоке - всегда под рукой
- Уведомления только в одном месте
- Запрос на вступление всегда виден
- Поп-ап подтверждает отправку заявки

### 3. Визуальная ясность

**Было:**
- Перегруженный профиль
- Смешанные функции
- Неочевидная навигация

**Стало:**
- Минималистичный блок "Я"
- Полноценный блок "Семья"
- Понятные иконки и названия
- Логичная структура

### 4. Масштабируемость

**Было:**
- Сложно добавлять новые функции
- Риск дублирования
- Запутанная структура

**Стало:**
- Легко добавлять функции в "Семья"
- Нет риска дублирования
- Чёткая структура для развития
