## 📊 Технические детали

### Polling для обновления прав

**Интервал:** 10 секунд

**Логика:**
```typescript
useEffect(() => {
  loadRecipes();
  loadUserData();
  
  // Polling для обновления данных семьи (проверка смены ролей)
  const familyPollInterval = setInterval(() => {
    loadUserData();
  }, 10000); // Каждые 10 секунд
  
  return () => clearInterval(familyPollInterval);
}, []);
```

### Проверка прав на удаление

**Frontend:**
```typescript
const canDeleteRecipe = (recipe: Recipe): boolean => {
  if (!currentUser || !userFamily) return false;
  
  // Глава семьи может удалить любое блюдо
  if (userFamily.owner_id === currentUser.id) return true;
  
  // Поварушка может удалить любое блюдо
  const member = userFamily.members?.find((m: any) => m.id === currentUser.id);
  if (member && member.role === 'chef') return true;
  
  return false;
};
```

**Backend:**
```php
// Глава семьи или поварушка могут удалить любое блюдо
$stmt = $db->prepare("
    SELECT f.owner_id, fm.role
    FROM families f
    JOIN family_members fm ON f.id = fm.family_id
    WHERE fm.user_id = ? AND fm.status = 'accepted'
");
$stmt->execute([$userId]);
$family = $stmt->fetch();

if ($family) {
    if ($family['owner_id'] == $userId || $family['role'] === 'chef') {
        $canDelete = true;
    }
}
```

## 🐛 Решение проблем

### Проблема 1: Кнопки удаления не появляются после назначения поварушки

**Решение:**
1. Подождите 10 секунд (polling обновит данные)
2. Обновите страницу (F5)
3. Проверьте консоль на наличие ошибок

### Проблема 2: Ошибка "У вас нет прав на удаление этого блюда"

**Решение:**
1. Проверьте, что вы являетесь главой семьи или поварушкой
2. Убедитесь, что вы состоите в семье
3. Проверьте логи backend

### Проблема 3: Страница "прыгает" при смене вида

**Решение:**
1. Убедитесь, что загружен новый файл `RecipeList.tsx`
2. Очистите кэш браузера (Ctrl+Shift+R)
