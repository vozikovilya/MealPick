# 📋 Улучшения блока "Спросить" - Версия 2.0

## ✅ Что было улучшено

### 1. Улучшенный UI секции "Кому отправить?"

**Было:**
- Простые кнопки "Всей семье" / "Конкретному участнику"
- Выпадающий список для выбора одного участника

**Стало:**
- Красивые градиентные кнопки с иконками
- Режим "Всей семье" - отправка всей семье
- Режим "Выбрать участников" - множественный выбор участников
- Чекбоксы для выбора нескольких участников
- Счётчик выбранных участников
- Отображение ролей участников (Глава семьи 👑, Поварушка 👨‍🍳)
- Плавная анимация появления/скрытия списка участников

**Визуальные улучшения:**
- Градиентные кнопки (оранжевый → янтарный)
- Иконки для каждого режима
- Аватары участников
- Бейджи ролей
- Анимация при выборе

---

### 2. Множественный выбор получателей

**Новая логика:**
- Можно выбрать **несколько участников** одновременно
- Каждый выбранный участник получает отдельный запрос
- В модалке подтверждения отображается список всех получателей

**Примеры:**
- Выбран 1 участник → "Мария скоро ответит"
- Выбрано 2 участника → "2 человек скоро ответят"
- Выбрано 3+ участника → "3 человек скоро ответят"

---

### 3. Улучшенная модалка подтверждения

**Новая функциональность:**
- Отображает информацию о получателях
- Для отправки всей семье:
  - Иконка семьи 👥
  - Текст "Отправлено всей семье"
  - Название семьи
- Для отправки конкретным участникам:
  - Список всех выбранных участников
  - Аватары и имена каждого участника
  - Красивое оформление с градиентом

**Дизайн:**
- Градиентный фон для информации о получателях
- Фиолетовый градиент для отправки всей семье
- Синий градиент для отправки конкретным участникам
- Анимация появления

---

### 4. Новый экран "Детали запроса"

**Назначение:**
- Показывает полную информацию о запросе
- Отображает статусы ответов всех участников
- Показывает кто что выбрал

**Функциональность:**

#### Информация о запросе:
- Аватар и имя отправителя
- Дата и время отправки
- Статус запроса (⏳ Ожидает / ✅ Завершён)
- Милое сообщение (если есть)
- Количество получателей

#### Статусы ответов:
- Список всех получателей
- Для каждого получателя:
  - ✅ Ответил (зелёный фон, галочка)
  - ⏳ Ожидает ответа (серый фон, часы)
  - Количество выбранных блюд

#### Выбранные блюда по участникам:
- Группировка по участникам
- Для каждого участника:
  - Аватар и имя
  - Список выбранных блюд с фото
  - Название и описание каждого блюда
  - Галочка ✅ для выбранных блюд

#### Все блюда в запросе:
- Полный список блюд, которые были отправлены
- Для каждого блюда:
  - Фото, название, описание
  - Счётчик "Выбрано: X" - сколько раз это блюдо выбрали

## 🗄️ Обновлённая структура базы данных

### Таблица `swipe_requests`

**Новые поля:**
- `to_user_id` - ID получателя (NULL если отправлено всей семье)
- `to_family_id` - ID семьи (NULL если отправлено конкретному пользователю)
- `responses` - JSON объект с ответами всех участников

**Пример `responses`:**
```json
{
  "1": [1, 3, 5],      // Пользователь 1 выбрал блюда с ID 1, 3, 5
  "2": [2, 4],         // Пользователь 2 выбрал блюда с ID 2, 4
  "3": []              // Пользователь 3 ещё не ответил
}
```

## 🔌 Обновлённые API Endpoints

### POST /api/swipe/create.php

**Новые параметры:**
```json
{
  "recipe_ids": [1, 2, 3],
  "to_user_id": 2,              // ID конкретного получателя
  "to_family_id": 1,            // ID семьи (если отправлено всей семье)
  "mode": "select",
  "category": null,
  "message": "Что будем кушать?",
  "delivery_ids": null
}
```

**Логика:**
- Если `to_family_id` указан - создаётся один запрос для всей семьи
- Если `to_user_id` указан - создаётся запрос для конкретного пользователя
- Frontend отправляет отдельный запрос для каждого выбранного участника

- ✅ N уведомлений создаётся
- ✅ Каждый участник отвечает независимо
- ✅ Отправитель видит статусы всех ответов
