# Исправление проблемы с данными между пользователями

## 🐛 Описание проблемы

При выходе из одного профиля и входе в другой, данные предыдущего пользователя (меню семьи, профиль семьи, уведомления) оставались видимы новому пользователю.

## 🔍 Причина проблемы

В функциях `login()` и `register()` данные не фильтровались по текущему пользователю. Все данные хранились в глобальном состоянии store и отображались всем пользователям без проверки принадлежности.

## ✅ Решение

### 1. Исправлена функция `login()`

Теперь при входе пользователя:
- Проверяется, является ли пользователь членом семьи (`familyProfile.memberIds.includes(user.id)`)
- Если да - показывается профиль семьи
- Если нет - `familyProfile = null`
- Уведомления фильтруются по `currentUserId`
- Запросы на выбор блюд фильтруются по `currentUserId` и `familyProfile`

```typescript
login: (emailOrUsername, password) => {
  const { users, familyProfile, notifications, swipeRequests } = get();
  const user = users.find(...);
  
  // Проверяем принадлежность к семье
  const userFamily = familyProfile && familyProfile.memberIds.includes(user.id) 
    ? familyProfile 
    : null;
  
  // Фильтруем уведомления
  const userNotifications = notifications.filter((n) => 
    n.fromUserId === user.id || 
    (userFamily && userFamily.memberIds.includes(n.fromUserId))
  );
  
  // Фильтруем запросы
  const userSwipeRequests = swipeRequests.filter((r) => 
    r.fromUserId === user.id || 
    (r.toUserId === user.id) ||
    (r.toFamilyId && userFamily && r.toFamilyId === userFamily.id)
  );
  
  set({ 
    currentUserId: user.id,
    familyProfile: userFamily,
    notifications: userNotifications,
    swipeRequests: userSwipeRequests,
    pendingNotification: null,
  });
}
```

### 2. Исправлена функция `register()`

При регистрации нового пользователя:
- Очищается `familyProfile` (новый пользователь не в семье)
- Очищаются `notifications` (нет уведомлений)
- Очищаются `swipeRequests` (нет запросов)
- Очищается `pendingNotification`

```typescript
register: (email, username, password, name, avatar = '👤') => {
  const newUser: User = { ... };
  
  set({
    users: [...users, newUser],
    currentUserId: newUser.id,
    // Очищаем данные предыдущего пользователя
    familyProfile: null,
    familyJoinRequests: [],
    notifications: [],
    swipeRequests: [],
    pendingNotification: null,
  });
}
```

### 3. Исправлена функция `logout()`

При выходе очищаются чувствительные данные:
- `familyProfile = null`
- `pendingNotification = null`

```typescript
logout: () => {
  set({ 
    currentUserId: null,
    familyProfile: null,
    pendingNotification: null,
  });
}
```

## 📊 Как это работает

### Сценарий 1: Выход и вход другого пользователя

1. Пользователь А выходит (`logout()`)
   - `currentUserId = null`
   - `familyProfile = null`
   - `pendingNotification = null`

2. Пользователь Б входит (`login()`)
   - Проверяется, есть ли у Б семья
   - Если есть - показывается его семья
   - Если нет - `familyProfile = null`
   - Фильтруются уведомления и запросы для Б

### Сценарий 2: Регистрация нового пользователя

1. Новый пользователь регистрируется (`register()`)
   - Создаётся новый пользователь
   - Очищаются все данные предыдущего пользователя
   - Новый пользователь видит только свои данные (пустое меню, нет семьи)

### Сценарий 3: Пользователь в семье

1. Пользователь А создаёт семью
   - `familyProfile` создаётся с `memberIds = [А.id]`

2. Пользователь Б присоединяется к семье
   - `familyProfile.memberIds` обновляется: `[А.id, Б.id]`

3. Пользователь А выходит и входит снова
   - `login()` проверяет: `familyProfile.memberIds.includes(А.id)` → true
   - Показывается семья с обоими пользователями

4. Пользователь В входит (не в семье)
   - `login()` проверяет: `familyProfile.memberIds.includes(В.id)` → false
   - `familyProfile = null`
   - Пользователь В видит только свои рецепты

## 🎯 Результат

✅ Каждый пользователь видит только свои данные:
- Свои рецепты (или рецепты своей семьи)
- Свой профиль семьи (если является членом)
- Свои уведомления
- Свои запросы на выбор блюд

✅ Данные не смешиваются между пользователями

✅ При выходе и входе другого пользователя данные корректно фильтруются

✅ При регистрации нового пользователя данные предыдущего очищаются

1. Войдите как пользователь А

3. Добавьте несколько блюд
4. Выйдите
5. Войдите как пользователь Б
6. ✅ Убедитесь, что семья пользователя А не видна

### Тест 2: Регистрация нового пользователя
1. Войдите как пользователь А
2. Создайте семью, добавьте блюда
3. Выйдите
4. Зарегистрируйте нового пользователя В
5. ✅ Убедитесь, что данные пользователя А не видны
6. ✅ Убедитесь, что у пользователя В пустое меню и нет семьи

### Тест 3: Пользователь в семье
1. Пользователь А создаёт семью
2. Пользователь Б присоединяется по ссылке
3. Пользователь А выходит и входит снова
4. ✅ Убедитесь, что семья видна обоим пользователям
5. Пользователь В входит (не в семье)
6. ✅ Убедитесь, что семья А и Б не видна пользователю В

## 📝 Примечания

- Данные хранятся в localStorage для всех пользователей
- Фильтрация происходит на уровне store при login/register/logout
- Компоненты получают уже отфильтрованные данные из store
- Это обеспечивает безопасность и изоляцию данных между пользователями
