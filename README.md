# MealPick - Выбираем блюда вместе

Приложение для совместного выбора блюд в семье или компании.

## 🚀 Развертывание на Vercel

### Быстрое развертывание

1. **Подключите репозиторий к Vercel**
   - Перейдите на [vercel.com](https://vercel.com)
   - Нажмите "Add New Project"
   - Выберите ваш репозиторий GitHub

2. **Настройки проекта**
   - Framework Preset: **Vite**
   - Build Command: `npm run build`
   - Output Directory: `dist`
   - Install Command: `npm install`

3. **Деплой**
   - Нажмите "Deploy"
   - Дождитесь завершения сборки
   - Получите URL вашего приложения

### Ручное развертывание через CLI

```bash
# Установите Vercel CLI
npm i -g vercel

# Войдите в аккаунт
vercel login

# Разверните проект
vercel

# Для production
vercel --prod
```

## 📋 Конфигурация

### vercel.json

Файл `vercel.json` уже настроен для корректной работы SPA:

```json
{
  "rewrites": [{ "source": "/(.*)", "destination": "/index.html" }]
}
```

Эта конфигурация обеспечивает правильную работу клиентского роутинга.

### Переменные окружения

Приложение использует localStorage для хранения данных, поэтому дополнительные переменные окружения не требуются.

## 🛠️ Локальная разработка

```bash
# Установка зависимостей
npm install

# Запуск dev сервера
npm run dev

# Сборка для production
npm run build

# Предпросмотр production сборки
```
