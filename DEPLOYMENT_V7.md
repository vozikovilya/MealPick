## 🧪 Быстрое тестирование

### Тест 1: Редактирование семьи

1. Войдите как глава семьи
2. Перейдите в Профиль → Профиль семьи
3. Нажмите "Редактировать семью"
4. Измените аватар и название
5. Нажмите "Сохранить"
6. ✅ Данные должны обновиться

### Тест 2: Уведомления в реальном времени

**Подготовка:**
- Откройте приложение в двух браузерах
- Войдите как разные пользователи из одной семьи

**Тестирование:**
1. В Браузере 1 отправьте запрос на выбор блюд
2. В Браузере 2 подождите 5-10 секунд
3. ✅ Должно появиться toast уведомление
4. Нажмите "Выбрать блюда"
5. Выберите блюда и отправьте ответ
6. В Браузере 1 подождите 5-10 секунд
7. ✅ Должно появиться toast уведомление об ответе

## 📊 Технические детали

### Polling механизм

- **Интервал проверки:** 5 секунд
- **Автозакрытие уведомлений:** 10 секунд
- **Позиция уведомлений:** Правый верхний угол

### API Endpoints

**Новый endpoint:**
```
PUT /api/family/update.php

**Параметры:**

```

## 🐛 Решение проблем

### Уведомления не появляются

1. Проверьте, что вы авторизованы
2. Откройте консоль браузера (F12)
3. Проверьте на наличие ошибок
4. Убедитесь, что загружены новые файлы

### Кнопка "Редактировать семью" не видна

1. Убедитесь, что вы являетесь главой семьи
2. Очистите кэш браузера (Ctrl+Shift+R)
3. Проверьте, что загружен новый файл `ProfileScreen.tsx`
