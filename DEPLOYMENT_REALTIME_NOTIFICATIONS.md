## 📊 Технические детали

### Polling система

**App.tsx (глобальный polling):**
- Интервал: 5 секунд
- Назначение: Toast уведомления на всех страницах
- Обновляет: Счётчик непрочитанных в хедере

**Notifications.tsx (локальный polling):**
- Интервал: 3 секунды
- Назначение: Обновление списка на странице уведомлений
- Обновляет: Список уведомлений, статусы прочтения

### Оптимизации

1. **Умное обновление:**
   - Проверяет наличие новых уведомлений
   - Проверяет изменения статусов
   - Обновляет только при наличии изменений

2. **Фоновые API запросы:**
   - Автопрочтение не ждёт ответа сервера
   - Ошибки логируются, но не блокируют UI
   - Мгновенный отклик для пользователя

3. **Оптимизированные анимации:**
   - `layout` prop для плавного перемещения
   - `AnimatePresence` с `initial={false}`
   - Spring анимация для естественного движения
